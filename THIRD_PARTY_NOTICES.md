### Shopify Atelier

**This competition application does not redistribute the Shopify Atelier theme.** No Shopify theme code, theme configuration or Shopify-generated block is included, and nothing in this repository claims ownership of Shopify material.

Daylite Digital's earlier storefront ran on Shopify's Atelier theme. The theme's stock code (sections, blocks, snippets, assets, locales, templates and configuration) was removed from this repository, and nothing here is claimed as Daylite's or MIT-licensed work derived from it. Theme configuration files that mix Atelier's structure with Daylite settings were also left out, because the Daylite parts cannot be cleanly separated. Two blocks generated by Shopify's in-editor AI tool were left out for the same reason (provenance of tool output not established).

The two retained snippets are Daylite's own CSS and JavaScript. They target a Shopify page and are not a copy of any theme file.

The theme loaded images by Shopify file URL; no image or other binary asset is included in this repository.
